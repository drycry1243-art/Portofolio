# Jovan Dave · Portfolio

Personal portfolio of Jovan Dave, an offensive security student at BINUS University (CRTA certified).
Built with Next.js (App Router) and Tailwind CSS, in a dark "hacker terminal / case file" style.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Edit content

All text lives in `src/data/profile.ts`: profile, stats, case files (projects), skills, certification and experience.
Add a project by appending to `cases`.

## Deploy

Import this repository on [vercel.com/new](https://vercel.com/new). Vercel detects Next.js automatically; no settings needed.
